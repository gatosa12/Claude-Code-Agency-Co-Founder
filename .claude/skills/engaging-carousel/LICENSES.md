# Third-party components

Bundled:
- GSAP 3.15 (`assets/vendor/gsap.min.js`) — GreenSock standard "no charge" licence (free, including commercial use).
- Fonts (`assets/fonts/`): Inter, Playfair Display, Bodoni Moda, JetBrains Mono (SIL Open Font License 1.1); Arimo (Apache 2.0).
- Code in `components/` and `scripts/`: original, free to use, remix and share. The device library and the treatments
  come from the creator's Editor V1 skill.

Installed or downloaded on first use (not bundled):
- Kokoro-82M (Apache-2.0) via kokoro-onnx (MIT) — the narrator.
- faster-whisper (MIT) + Whisper small.en (MIT) — word timings and the intelligibility check.
- numpy, opencv-python-headless, pillow, soundfile — image and audio processing.
- HyperFrames (open source, via npx) — HTML → MP4 rendering.
- Sound effects: synthesised on each machine by `scripts/sfx_kit.py` (seeded noise and sines, no samples): nothing to
  license or credit. (The original kit downloaded Mixkit sounds; see REBUILT.md.)

Found per carousel (credited in each project's SOURCES.md and in the post caption via `scripts/credits.py`):
- Wikimedia Commons pictures (public domain, CC0, CC BY, CC BY-SA), NASA (public domain), Mixkit stock video
  (Mixkit Stock Video Free License), archive.org items (check each).

Your background track is yours: use one you own or have the rights to.
